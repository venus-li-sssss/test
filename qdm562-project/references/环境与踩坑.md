# 从零搭 QDM562 上位机升级环境：踩过的坑与验证方法

这份是"下次别再踩一遍"的清单，每条都包含现象 → 原因 → 正确做法。

## 一、端口类

1. **把 debug 口和上位机口搞反**
   现象：抓 debug 日志抓一小时 0 字节；上位机打开串口失败。
   原因：两个口都是 `USB Serial Port`，只能靠行为区分。
   做法：`COM3`=debug（静默，重启/升级才打）、`COM184`=上位机（5A A5）；`COM29`=串口日志（一直刷）。

2. **人工抓取占了脚本要用的口**
   现象：脚本报打开串口失败 / GNSS 版本读不到。
   原因：串口独占，人工实例（`default`/`qdm562debug`）不在脚本 `/killall:qdm562cap` 的清理范围。
   做法：`COM29` 永不人工占用；人工只抓 `COM3`。

3. **以为 0 字节就是没在抓**
   现象：用户看日志文件 0 字节，判定"你根本没抓"。
   原因：debug 口平时静默；且工具写文件时目录里显示的 `Length` 会滞后。
   做法：判活看 `st.json`（`state=running` / `pid` / `targets[].state=● 已连接` / `updated_at` 刷新），不看大小。

4. **手工开了抓取窗口又让脚本跑**
   现象：COM29 打不开，抓取一直红字重试。
   做法：跑脚本前 `/killall:default` 或关掉所有人工窗口。

## 二、版本口径类

5. **ATI 的 764 被当成真实版本**
   `ATI` 报 `..._764`，但设备实际是 **0765**（串口日志 `ver:0765` 为准）。按 764 挑差分包/对照 GNSS Build 会全错。

6. **GNSS Build 对照记反**
   `0765 → Build19128`、`0766 → Build27526`。日志里同时有 `$PDTINFO,...Build19128,...` 与 `FWVer R2001R3.3.3.0Build19128` 两条，取任一都可交叉验证。

## 三、脚本类

7. **脚本按写死的 `com48_*.log` 找日志**
   本机是 `com29_*.log` → 永远 found=False。改匹配规则（按配置生成 + 兜底）+ 改时间戳正则 + 改报错文案。

8. **用 `python` 直接跑**
   本机 `python` 可能指向别的运行时；固定用绝对路径
   `C:\Users\DELL\AppData\Local\Programs\Python\Python310\python.exe`。

9. **改了 device.yaml 没验证**
   跑一遍 import / 脚本头部打印，确认 `COM`、`check_gnss`、`gnss_com`、`gnss_capture_port` 真生效。

## 四、bat 启动类（最容易白跑）

10. **路径含括号 → `... was unexpected at this time`**
    `D:\QDM562\脚本\上位机升级(查GNSS版本)\` 里的 `)` 会被 cmd 当成代码块结束。
    做法：不用 `if exist ... ( ... )`，改 `if not exist ... goto :label`。

11. **bat 里的中文提示被拆坏**
    `chcp 65001` + 中文 echo → 出现一堆 `'xxx' is not recognized`。
    做法：bat 提示写英文，中文交给 python 输出。

12. **既要看得见又要留档**
    `python -u "x.py" %* 2>&1 | powershell -NoProfile -Command "$input | Tee-Object -FilePath 'runlog\run_%TS%.log'"`
    实测流式双写（文件每秒增长）；异常栈屏幕 + 文件都有。

13. **Ctrl+C 后窗口消失看不到异常**
    在 `pause` 前不要 `exit`；Ctrl+C 让 python 打 `KeyboardInterrupt`，bat 继续收尾并 `pause`，窗口保留。

14. **Ctrl+C 后残留抓取实例**
    收尾段加 `日志抓取.exe /killall:qdm562cap`（路径最好用 8.3 短名，避免中文）。

## 五、环境类

15. **抓取 exe 放 D 盘被安全软件删**
    只能放 C 盘（`C:\QDM562\日志抓取\`）。

16. **长压测被锁屏/休眠打断**
    见 SKILL.md 第 8 节配方：powercfg 四项 + 注册表三项 + F15 常驻自启。

17. **云盘搜长文件名搜不到**
    搜索把 query 截断到 30 字符 → 用短关键词（`rollback_766`、`diff_upgrade`）。

## 六、验证动作（做完必须核）

- `python scripts/port_probe.py` 结论与 `device.yaml` 一致；
- 抓取实例 `st.json` 里 `state=running` 且目标口 `● 已连接`；
- 脚本解析函数对真机日志返回 `Build19128`；
- 上位机 GUI 手发一条 5A A5 种子帧，串口日志出现 `_5AA5 Receive`；
- bat 用假脚本干跑一次，确认异常能在屏幕看到 + `runlog` 有记录（不用真升级）。
