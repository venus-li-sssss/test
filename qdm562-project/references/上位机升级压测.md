# QDM562 上位机升级压测（含 GNSS 版本校验）

## 一、链路

```
上位机 GUI（NinebotPluginPlatform.exe / 串口工具 v1.0.2）
        │  COM184（5A A5 请求帧）
        ▼
   设备（EG800AKCN_91LC）
        │  COM29（串口日志：$PDTINFO / FWVer / Monitor）
        ▼
  日志抓取.exe（qdm562cap 实例）→ C:\QDM562\gnss_log\com29_*.log
        │
        ▼
  脚本解析 Build 号 → 与 0765/0766 对照 → PASS/FAIL
```

三路日志（失败时按时间对齐排查）：串口日志 `COM29`（脚本自动抓）、CAT LOG `COM31`（CATStudio 手工录）、debug 日志 `COM3`（抓取工具常驻，重启/升级才有输出）。

## 二、5A A5 帧与 GUI 操作

- 帧结构（实战用过的三条种子帧）：`5A A5 01 3E 09 01 02 02 B2 FF`（源 ID 3E、目标 09、cmd 01、index 02）
- GUI 面板：串口设置（COM184 / 115200 / 200ms）、传输记录、右侧页签（组件信息 / 通用工具 / RxTx 工具）、固件下载（起始帧超时 2000、校验帧 3000、IAP3 100、协议 5AA5、源 ID 3E、目标 ID 09、固件路径）、协议组包、数据发送。
- 设备侧收到帧的日志形态：`_5AA5 Receive 5AA5 cmd:len:1,src:3e,dst:9,cmd:1,index:2,data:2.`
- 判定"上位机口通不通"的最快办法：发一条种子帧 → 串口日志有 `_5AA5 Receive` = 发送方向通；GUI「传输记录」出现 `[Rx]` = 接收方向也通。

## 三、脚本执行顺序（V3.1）

1. 读 `device.yaml`（端口、日志目录、GNSS 开关、差分包路径）
2. `/killall:qdm562cap` 清上次残留 → 拉起 `日志抓取.exe` 抓 `COM29`
3. 上位机 GUI 选 `COM184` 打开串口 → 按固件下载面板发帧 → 升级
4. 升级完设备重启 → 等日志里 `$PDTINFO` / `FWVer` 出现 → 解析 Build 号
5. 与 `0765_gnss_build_version`（Build19128）/ `0766_gnss_build_version`（Build27526）比对
6. 记录 PASS/FAIL，进入下一轮；结束 `/killall:qdm562cap`

## 四、GNSS 版本读取的关键实现（已修的 bug）

原脚本（作者机器）：

```python
files = glob(f"{gnss_log_dir}/com48_*.log")     # 写死作者机器上的口
```

本机抓出来是 `com29_*.log` → 永远匹配不到 → 版本号读不到。修法（三处最小改动）：

1. 匹配改成按配置生成：`com{port}/*.log`（port 取 `gnss_capture_port` / `gnss_com` / `gnss_version_com`），找不到再兜底 `com*_*.log`
2. 报错文案同步改，否则日志误导排查方向
3. 时间戳解析正则 `com48_(\d{8})_(\d{6})` → `com\d+_(\d{8})_(\d{6})`

验证方式：直接调脚本自身的解析函数读真机日志，返回 `found=True, build='Build19128'` 才算过。

## 五、脚本发起的抓取 vs 手工抓取（必须分实例）

| 谁 | 实例名 | 抓什么口 | 结束方式 |
|---|---|---|---|
| 压测脚本 | `qdm562cap` | `COM29`（固定） | 脚本自己 `/killall:qdm562cap` |
| 人工 debug | `qdm562debug` | `COM3` | 关窗口或 `/killall:qdm562debug` |
| 临时排查 | `ai1` | 任意 | 同上 |

**互斥关系**：同一串口只能一个程序打开。`COM184` 要跑上位机 → 抓取实例不能占它；`COM29` 永远留给脚本。

## 七、判定标准

- 版本从 0765 → 0766（或按计划反向回滚），
- GNSS Build 与版本对照表一致（0765=Build19128 / 0766=Build27526），
- 压测 PASS RATE 100%，
- 三路日志齐全（COM29 / CAT31 / COM3），失败轮次能按时间戳对齐三份日志。
